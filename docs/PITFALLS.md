# Known pitfalls

Symptom, cause and fix for traps this project has already hit. Read before touching the area named.

| Area | Symptom | Cause | Fix |
|---|---|---|---|
| Profiles | Schema rejects a profile with "Star counts average … too far from the Google rating" | The five star counts don't average to the rating shown (allowed drift is 0.05) | Adjust the counts; keep their total equal to the Google review count |
| Profiles | Schema rejects a "Fix soon" gap | Every entry in `summary.criticalGaps` needs an action due now or soon whose `fixesGap` repeats it word for word | Add or edit the matching opportunity's `fixesGap` |
| Profiles | Progress chart jumps after a scoring change | Past scores in `history` are recorded values; only the current month is computed | After changing `scoring.config.ts`, recheck each sample profile's recorded history so the trend still makes sense |
| Profiles | Schema rejects history with "Review totals can only grow" | A month's total is lower than the month before, or than today's platform totals | Fix the totals; the new-reviews bar chart depends on them rising |
| Tests | A profile test fails on `sampleData` | Every committed profile must be marked as sample data | Keep it `true`; real data belongs in a private fork |
| Styles | A table overflows on phones | Wide tables need `stack-table` and `data-label` on each cell, plus `hide-narrow` on bar columns | Add both; check at 320px with no sideways scroll |
| Styles | Hover or print colours look wrong in dark mode | Colours set outside `tokens.css`, or a missing dark token | Only use `var(--color-*)`; add new tokens to both the light and dark blocks |
| Print | Report prints dark | `data-mode` stays dark | `main.ts` switches to light on `beforeprint`; keep that listener |
| Git | The private source folder shows up as untracked | It sits inside the repo folder on the owner's Mac | It is listed in `.git/info/exclude`; never `git add -A` without checking `git status` first |
| Landing | Test "were drawn from the figures the app computes" fails | A profile or scoring change moved Brasa Taquería's figures, and the hero frames still show the old ones | Update `hero-sequence/content.json` from the test's diff, then re-render (`hero-sequence/README.md`) |
| Landing | A visible line where the hero meets the next section | The frames' edges no longer match `--color-stage` | Re-render after changing that token; the vignette in `hero-sequence/*.html` settles every edge to it |
| Landing | The closing words overlap the ticket on some laptops | 16:9 frames cropped to a squarer screen pull the scene left | `framingFor` switches to the 4:5 frames below 1.45:1; keep the hero text column at `min(24rem, 33vw)` |
| Landing | A render stops with `render_cancelled_parent_exited` | HyperFrames cancels a render when the shell that started it exits | Run it in a terminal that stays open, or as one foreground command |
| Review | Screenshots show half-filled bars or a blank hero | Full-page captures freeze CSS animations and break the pinned hero | Take viewport screenshots after scrolling to each part |
| Links | Old shared links (`/?r=…&tab=…`) land on the landing page | The report moved to `/report/` | `public/boot.js`, loaded first by both pages, forwards them; keep it (it is a file because the site allows no inline scripts) |
| Landing | The hero's call to action can't be reached with Tab, or a click at the top of the page opens the report | Faded blocks of words all share one grid cell; `visibility: hidden` drops them from focus and screen readers, and without `pointer-events: none` an invisible link catches clicks | Keep `.beat.is-off { pointer-events: none }` and the `focusin` handler in `landing.ts` that scrolls to a focused block |
| Styles | A see-through bar shows text sharp behind it in the built site | Writing `-webkit-backdrop-filter` after `backdrop-filter` makes the minifier keep only the prefixed copy | Write `backdrop-filter` alone; a test in `tests/landing.test.ts` refuses the prefixed form |
| Print | The ticket prints with its shadow | `.ticket-lift` is defined after the print block, so a print reset of equal weight loses | The print reset uses `.scorecard .ticket-lift` |
| Landing | The hero's plates slide under the pinned top bar | The frames were composed for the full screen height | The wide camera keys carry a `lift`; `cameraAt` widens the lens by the same factor so the lift moves the picture down without zooming in |
| Landing | The dark counter shows blocks and bands | WebP splits low-contrast darks into 16px blocks at any quality | Frames are AVIF with full-resolution colour; `end.webp` is the fallback for browsers without AVIF |
| Styles | Phone tables show meters and cut off columns at 390px | A new `@media` block was pasted inside the 40rem block, moving its rules to a narrower breakpoint | Keep each breakpoint's rules in one block; a test checks the phone rules sit under 40rem |
| Landing | Two blocks of hero words show at once, both half faded | A fade that starts before a block's range and ends after it overlaps the next block | `beatOpacity` fades inside each range; a test sweeps the scroll and allows one block at a time |
| Landing | A grey smear in the bar where the hero meets paper | The bar's backdrop blur mixes the dark stage and the paper behind it | Both top bars are solid with no blur; the landing bar takes the look of the section just below it |
| Landing | With reduced motion the finished frame slides under the words | The stage grows taller than the screen, and covering it scales the frame up | The still canvas keeps one screen's height on landscape screens; on portrait ones it runs the stage's full height and the words leave room below them for the frame |
| Landing | On portrait and square screens the words sit on top of the ticket and plates | The tall frame was fitted to the whole screen | `fitRect` takes the words' footprint and fits the frame into what is left, down to a floor. The footprint comes from layout offsets, which ignore the fades' transforms |
| Landing | A soft band covers the plates at the sides of the frame | The edge fade ran inward over the frame, and the end frame's plates sit within 4% of its sides | Nothing is painted over the frame: its edge, averaged so the grain doesn't streak, carries on outward into the gap and eases into the stage |
| Landing | The still canvas shrinks to a small strip at the top | An absolutely positioned canvas with `height: auto` takes its own size (300×150) instead of stretching between `top` and `bottom` | Give it `height: 100%` |
| Landing | The landing prints dark for a visitor in dark mode | Print followed the page's mode | `beforeprint` switches to light and `afterprint` puts the visitor's mode back, as the report does |
| Landing | On a phone held sideways every hero heading loses its first line under the bar | Display sizes followed the width only, and the words centred on the full screen height, bar included | A short-landscape block (`max-height: 30rem`) slims the bar, sizes type by height too, and centres the words below the bar |
| Landing | On ultrawide screens the ticket's footer runs off the bottom | Covering a screen wider than 16:9 crops the frame's top and bottom | Wider than the frame, `fitRect` fits the height and centres it; the edges carry outward as for tall frames |
| Landing | Every visitor downloads all 120 frames, 3 to 5 MB, before scrolling | Every frame was requested at load | The first and last frames and every sixteenth load at once; the rest start on the first scroll |
| Landing | The hero lags behind the scroll on a retina MacBook, about 15 frames a second | Drawing an AVIF from an `<img>` decodes it at draw time: 50 to 130 ms per new frame, even after `image.decode()`, which Chrome doesn't keep for canvas draws. Retina screens also got the 3200 set when 2560 was enough | Frames are fetched as files and decoded off the main thread with `createImageBitmap` into a window around the wanted frame, sized from a 256 MB budget; only decoded frames are drawn. The 3200 set only goes to screens that need more than 2600 pixels. Measured on the owner's MacBook: 67 ms a frame before, 17 ms after |
| Report | On phones the open tab sits off-screen or under the edge fade | The tab row scrolled only when focus moved, and the fade covered the row's last 15% | `revealTab` scrolls the open tab clear of the fade; the fade width is the row's end scroll padding, and a spacer lets the last tab clear it |
| Landing | The ticket's top slides under the bar on a phone held sideways, and a panel touches it at 1024x768 | Frames fitted to the full stage height, and the bar covers its top | `fitRect` takes the bar's height and fits wider-than-frame and tall-beside-words frames below it. Check by sweeping the scroll and sampling the canvas row just under the bar for light pixels |
| Report | Tables that fit still take a tab stop that rings the whole table | Every table wrapper got `tabindex=0` | Only a table that scrolls sideways gets the stop, rechecked on tab change and resize |
| Report | The focused tab's ring loses its top and bottom | The sideways-scrolling row clips anything outside it | Tabs draw the ring inside (`outline-offset: -2px`) |
| Report | The Social tab's Accounts table runs past a phone screen, and "Not counted" past a 320px one | The table had no stacked layout, and numeric cells never wrap | The Accounts table restacks like the others; words standing in for a missing figure may wrap |
| Security | A bar, ring or chart shows unstyled or empty on the live site but works with `npm run dev` | The live site's Content-Security-Policy blocks `style` attributes and inline `<style>`; the dev server sends no policy | Draw with SVG attributes (`width`, `stroke-dashoffset`, `points`) and classes. Check with a server that sends the headers in `vercel.json` |
| Security | The console reports "This document requires 'TrustedScript' assignment" | Zod compiles its parsers with `new Function` unless told not to | `z.config({ jitless: true })` at the top of `src/schema.ts`; keep it |
| Security | A page is blank on the live site with a Trusted Types error | Something assigned a plain string to `innerHTML` | Use `setHtml` from `src/html.ts`, which goes through the one allowed policy |
| Styles | Text on a sheet is light on light, or a control on the stage is dark on dark | A colour token was read in the wrong context: the names mean ink on paper inside `.sheet` and light on steel outside | Put data inside a `.sheet`; for stage-only parts use the `--color-stage-*` and `--color-lamp` tokens |
| Review | Full-page screenshots show bars a quarter full | Full-page captures freeze the fill animations part-way | Capture with reduced motion turned on, or take viewport screenshots |
| Report | On phones a difference and its word sit at opposite edges | The stacked cell is a space-between flex row, so each child spreads out | Wrap the figure and its word in one span |

| Profiles | Schema rejects history with "History skips …" | The Progress charts show change from one month to the next, so a missing month would be drawn as one month's change | Add an entry for every month up to the one before `asOf`. Recorded scores are whole numbers, like the computed one |
